# yummywormy

My personal dev site, at **https://yummywormy1-stack.github.io**.

It's plain HTML, CSS and JS hosted on GitHub Pages.


## files

```
index.html        the page
404.html          not-found page
assets/
  style.css       styles (grayscale, follows the system light/dark setting)
  main.js         loads the project list from GitHub
  favicon.svg     squiggle icon
.nojekyll         tells GitHub Pages to serve files as-is (no Jekyll build)
```
